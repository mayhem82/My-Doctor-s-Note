    Settings

    Stored only in this browser's local storage, never sent anywhere but directly to Anthropic's API when you generate a distilled note or reconciliation. Anyone with access to this browser/device can read it back out - don't use this on a shared or public computer.

    Only required if the app shows an error mentioning "anthropic-workspace-id" - that means your API key isn't scoped to a single workspace. Find the ID under Settings → Workspaces in the Claude Console, and paste it here. Leave blank otherwise.
